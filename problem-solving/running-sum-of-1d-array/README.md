# Running Sum of 1D Array



## Pattern

Brute Force / Nested Loops



## Initial Approach

For each element, add all previous elements.



## Time Complexity

O(n²)



## Space Complexity

O(1)



## Optimized Approach

Prefix Sum / Running Sum



## Optimized Complexity

Time: O(n)

Space: O(1)
