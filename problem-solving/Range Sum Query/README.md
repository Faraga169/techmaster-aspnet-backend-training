# \# NumArray - Range Sum Query

# 

# \## Pattern

# Brute Force / Linear Scan

# 

# \## Initial Approach

# For each `sumRange` query, loop from `left` to `right` and add all elements in the range.

# 

# \## Time Complexity

# O(n)

# 

# \## Space Complexity

# O(1)

# 

# \## Approach

# Store the input array inside the `NumArray` class, then iterate through the requested range and calculate the sum.

#
